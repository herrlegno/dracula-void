> A pure black Dracula-inspired theme plugin for JetBrains IDEs.

Dracula Void keeps the familiar Dracula palette, pushes the IDE UI toward true black surfaces, and bundles two theme variants that share the same editor scheme.

## Included themes

- `Dracula Void` - the main full-black UI theme.
- `Islands Dracula Void` - an Islands-based variant with the same editor colors.
- `Dracula Void` editor scheme - the bundled syntax and editor color scheme used by both UI themes.

## Install

Build the plugin ZIP locally:

```bash
./gradlew buildPlugin
```

Then install it in your IDE:

1. Open `Settings | Plugins`.
2. Choose `Install Plugin from Disk...`.
3. Select the ZIP from `build/distributions/`.
4. Restart the IDE and enable `Dracula Void`.
